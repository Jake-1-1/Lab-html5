LABORATORIO HTML5 - ESTRUCTURA BASICA DE UNA PAGINA WEB

Descripcion:
Este proyecto es una pagina web hecha con HTML5 y CSS. Muestra la sintaxis basica de HTML (html, head, body, encabezados, parrafos, listas y enlaces), el uso de etiquetas semanticas (header, nav, main, section, article, aside, footer) y caracteristicas nuevas de HTML5 como video, audio, canvas, figure y figcaption.

Contenido de la carpeta:
- index.html : pagina principal. Los comentarios dentro del codigo explican las caracteristicas de la estructura HTML5.
- styles.css : estilos de la pagina.
- imagenes/  : imagenes usadas en la pagina.
- audio/     : archivo de audio de prueba.
- video/     : grabacion de pantalla (demo.mp4) mostrando el trabajo.
- README.txt : este archivo.

Como verlo:
Abrir index.html en cualquier navegador.

Herramientas usadas:
Visual Studio Code, navegador web y GitHub.
